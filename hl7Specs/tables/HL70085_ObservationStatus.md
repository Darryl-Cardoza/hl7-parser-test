# HL7 Table 0085 — Observation Result Status

Used in: OBX-11

| Value | Description |
|-------|-------------|
| C | Record coming over is a correction |
| D | Deletes the OBX record |
| F | Final results |
| I | Specimen in lab; results pending |
| N | Not asked; testing not ordered |
| O | Order detail description only (no result) |
| P | Preliminary results |
| R | Results entered, not yet verified |
| S | Partial results |
| U | Results status change to final without retransmitting |
| W | Post original as wrong |
| X | Results cannot be obtained for this observation |
