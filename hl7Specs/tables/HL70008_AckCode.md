# HL7 Table 0008 — Acknowledgment Code

Used in: MSA-1

| Value | Description | Usage |
|-------|-------------|-------|
| AA | Application Accept | Message processed successfully |
| AE | Application Error | Message received but processing failed |
| AR | Application Reject | Message rejected (structural/protocol error) |
| CA | Commit Accept | Enhanced mode — committed to safe storage |
| CE | Commit Error | Enhanced mode — error during commit |
| CR | Commit Reject | Enhanced mode — rejected at commit |
